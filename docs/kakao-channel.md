# 카카오톡 채널 준비

상담은 카카오톡 채널 1:1 채팅으로 받습니다. 채널은 대표님 카카오 계정으로 직접 만들어야 합니다.
만든 뒤 `main.js` 맨 위 `KAKAO_CHANNEL` 한 줄만 바꾸면 사이트의 카톡 버튼이 전부 연결됩니다.

---

## 1. 채널 만들기 (10분)

1. **카카오 비즈니스** (business.kakao.com) 접속 → 카카오 계정으로 로그인
2. **채널 만들기** → 아래 2장의 문구를 넣습니다
   - 프로필 사진: 로고 또는 상호 글자 (사람 사진이나 은행 로고는 쓰지 않기)
   - 채널 이름 / 검색용 아이디 / 소개 문구
   - 카테고리: 금융 관련 항목 중 가장 가까운 것
3. 관리자센터 → **채팅** → **1:1 채팅 사용** 켜기 ← 이게 꺼져 있으면 상담을 못 받습니다
4. 관리자센터 → 채널 정보 → **채널 공개**, **검색 허용** 켜기
5. 관리자센터 → **채널 URL** 확인. `https://pf.kakao.com/_AbCdE` 형식입니다
6. `main.js` 맨 위를 이렇게 바꿉니다
   ```js
   const KAKAO_CHANNEL = '_AbCdE';
   ```
   스크립트가 꺼진 브라우저를 위해 `index.html` 안의 `_XXXXXX`도 같은 값으로 바꿉니다
   ```bash
   sed -i '' 's/_XXXXXX/_AbCdE/g' index.html main.js
   ```
7. (권장) **비즈니스 인증**: 채널 이름 옆에 인증 표시가 붙어 신뢰도가 오릅니다. 사업자등록증이 필요합니다. 금융 업종은 심사에서 대출모집인 등록증을 추가로 요구할 수 있습니다.

> 오픈 전 확인: 위탁 금융사가 모집인의 카카오 채널 운영과 상담 방식(채팅 기록 보관 등)을 허용하는지 준법감시 담당자에게 확인하세요. 채널 프로필과 메시지도 광고에 해당할 수 있어 심의 대상입니다.

## 2. 프로필 문구

**채널 이름** (예시 2개, 상호 확정 후 선택)
- [상호명] 전세퇴거자금 상담
- [상호명] 보증금 반환대출

**검색용 아이디**: `[상호영문]` (예: depositdesk)

**소개 문구** (한 줄)
> 전세퇴거자금 · 집 있는 분의 전세대출, 가능 여부부터 정확히 봐 드립니다

**프로필 하단 정보** (채널 정보 > 상세 설명, 반드시 포함)
```
대출모집인 [성명] · 등록번호 [제0000호]
위탁 금융회사 [금융사명] (1사 전속) · 계약 체결 권한 없음
고객에게 수수료를 받지 않습니다. 요구하면 불법이니 금융감독원(1332)에 신고하세요.
상담 시간 평일 9:00 – 18:00
등록 조회 loanconsultant.or.kr
```

## 3. 자동 메시지

### 친구 추가 환영 메시지
```
[상호명]입니다. 채널을 추가해 주셔서 감사합니다.

전세퇴거자금(임차보증금 반환대출)과 집이 있는 분의 전세대출을 상담합니다.
사이트에서 진단을 하셨다면 결과를 이 채팅창에 붙여넣어 주세요.
진단 전이라면 아래 세 가지만 알려 주셔도 됩니다.

1) 집주인인지, 세입자인지
2) 부부 합산 주택 수와 지역
3) 지금 전세계약을 맺은 날짜

상담은 무료이며 수수료를 받지 않습니다.
```

### 채팅방 첫 인사 (1:1 채팅 진입 시)
```
안녕하세요, [상호명] 상담사 [성명]입니다 (대출모집인 등록번호 [제0000호]).
진단 결과나 궁금한 점을 남겨 주시면 순서대로 답해 드립니다.
주민등록번호와 계좌 비밀번호는 묻지도 받지도 않습니다.
```

### 상담 시간 외 자동 응답
```
지금은 상담 시간(평일 9시 – 18시)이 아닙니다.
남겨 주신 내용은 다음 영업일 오전에 순서대로 답해 드립니다.
```

## 4. 상담사용 저장 답장 (관리자센터 > 채팅 > 자주 쓰는 문구)

**진단 결과를 받았을 때**
```
보내주신 결과 확인했습니다. 정확히 보려면 두 가지가 더 필요합니다.
1) 집을 산 날짜 (등기부 기준)
2) 지금 세입자와 전세계약을 맺은 날짜, 돌려줄 보증금
계약서 사진을 보내 주셔도 됩니다. 주민등록번호 부분은 가려 주세요.
```

**준비 서류 안내 (반환대출)**
```
은행 접수 때 필요한 서류입니다. 지금 다 모을 필요는 없고 상담 후 확정해 드립니다.
· 신분증, 주민등록등본
· 지금 임대차계약서 (확정일자 포함)
· 등기사항전부증명서
· 소득 증빙 (근로자: 원천징수영수증 / 사업자: 소득금액증명원)
```

**원칙상 어려운 경우**
```
말씀하신 조건은 현재 규정(기준일 2026.11.9)으로는 원칙상 어렵습니다.
다만 아래를 확인하면 길이 생길 수 있습니다.
· 주택 수에서 빠지는 집이 있는지 (분양권, 상속, 인구감소지역 주택 등)
· 다른 주택을 담보로 할 수 있는지
가능하지 않은 방법을 가능하다고 안내하지 않습니다.
```

**수수료 문의**
```
상담과 진행 모두 고객께 받는 수수료는 없습니다.
대출모집인의 보수는 금융회사에서만 받습니다. 누구든 수수료를 요구하면 불법이니 금융감독원(1332)에 신고해 주세요.
```

**은행 직원이냐는 문의**
```
저는 [금융사명]과 위탁계약을 맺은 등록 대출모집인입니다. 은행 직원은 아니며 계약은 금융회사가 직접 체결합니다.
등록번호 [제0000호]는 loanconsultant.or.kr 에서 확인하실 수 있습니다.
```

## 5. 채팅 상담에서 하지 말 것

- "무조건 됩니다", "승인 보장", "최저금리", "LTV 90%" 같은 단정·과장
- 사업자대출로 한도 늘리기 같은 규제 우회 권유 (고객도 3–10년 대출 제한)
- 주민등록번호, 계좌 비밀번호, 공동인증서 비밀번호 받기
- 채팅에서 금리 숫자를 말할 때 기준일과 "심사에 따라 달라질 수 있음" 빠뜨리기
- 친구 전체에게 홍보 메시지 보내기: 보내려면 (광고) 표시, 수신거부 방법, 심의필이 필요합니다
