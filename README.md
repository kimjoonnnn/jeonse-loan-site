# 전세퇴거자금 · 유주택자 전세대출 상담 사이트

정적 사이트 (HTML / CSS / JS, 빌드 없음). 미리보기: launch.json의 `jeonse-loan-site` (포트 4180).
규정 근거: `research/grok-research.md` (기준일 2026-11-09).

## 퍼널
첫 화면 진단기(질문 3–6개) → 결과 카드(가능 / 조건부 / 원칙상 어려움 + 근거 수치) → [이 결과로 상담 신청] → 휴대폰 번호 한 칸 + 필수 동의 → 접수.
진단 응답은 숨은 필드 `diagnosis`로 함께 전송되어 상담사가 바로 이어서 볼 수 있음.
진단을 건너뛰는 길: 상단 [상담 신청], 첫 화면 [진단 없이 바로 상담 신청], 상황별 기준 옆 버튼, 모바일 하단 고정 바(전화 · 카카오톡 · 상담 신청).

## 섹션
1. 첫 화면: 헤드라인 + 진단기 + 등록번호·위탁 금융사·수수료 0원
2. 사진 띠 (노원구) — 1억 상한 한 줄
3. 상황별 기준: 6개 탭 (수도권 1주택 / 2주택 이상 / 역전세 / 지방 / 임대사업자·법인 / 집 있는 세입자)
4. 상담하면 받는 것: 접수 문자 → 계약일 확인 → 예상 범위 (예시)
5. 자주 묻는 질문 8개
6. 상담 신청 (번호 한 칸) + 카카오톡·전화·담당 상담사 등록번호
7. 법정 고지 푸터

## 규정이 바뀌면
`main.js` 맨 위 `Q`(질문 흐름)와 `RESULTS`(결과 문구·수치), `index.html`의 상황별 탭 띠(`.bands`)와 FAQ를 고칩니다.
