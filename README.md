# 전세퇴거자금 · 유주택자 전세대출 상담 사이트

정적 사이트 (HTML / CSS / JS, 빌드 없음). 미리보기: launch.json의 `jeonse-loan-site` (포트 4180).
규정 근거: `research/grok-research.md` (기준일 2026-11-09).

## 퍼널 (상담은 카카오톡 채널)
첫 화면 진단기(질문 3–6개) → 결과 카드(가능 / 조건부 / 원칙상 어려움 + 근거 수치) → [카카오톡으로 이 결과 상담] → 진단 결과가 클립보드에 복사되고 채널 1:1 채팅이 열림 → 고객이 붙여넣기.
카톡이 어려운 고객용으로 휴대폰 번호 한 칸 폼을 보조로 남겨 둠 (진단 결과는 숨은 필드 `diagnosis`로 함께 전송).
카톡 버튼 위치: 상단 메뉴, 첫 화면, 상황별 기준, 상담 섹션, 푸터, 모바일 하단 고정 바(진단 · 전화 · 카카오톡 상담).

**채널 연결**: `main.js` 맨 위 `KAKAO_CHANNEL = '_XXXXXX'` 한 줄. 개설 순서·프로필 문구·환영 메시지·저장 답장은 `docs/kakao-channel.md`.

## 섹션
1. 첫 화면: 헤드라인 + 진단기 + 등록번호·위탁 금융사·수수료 0원
2. 사진 띠 (노원구) — 1억 상한 한 줄
3. 상황별 기준: 6개 탭 (수도권 1주택 / 2주택 이상 / 역전세 / 지방 / 임대사업자·법인 / 집 있는 세입자)
4. 상담하면 받는 것: 카톡으로 결과 전송 → 계약일 확인 → 예상 범위 (예시)
5. 자주 묻는 질문 8개
6. 상담: 카카오톡 상담 시작 버튼 + 보조 번호 한 칸 폼 + 채널 추가·전화·담당 상담사 등록번호
7. 법정 고지 푸터

## 규정이 바뀌면
`main.js` 맨 위 `Q`(질문 흐름)와 `RESULTS`(결과 문구·수치), `index.html`의 상황별 탭 띠(`.bands`)와 FAQ를 고칩니다.

## 오픈 전 반드시
- [ ] `[ ]`로 표시된 자리 전부 교체: 상호, 대표, 사업자번호, 주소, 대출모집인 등록번호, 위탁 금융사, 상담사 이름, 전화, 카카오 채널, 금리·연체이자·중도상환수수료, 심의필 번호·유효기간, 개인정보 보유기간
  확인: `grep -n "\[" index.html`
- [ ] 카카오톡 채널 개설 후 `KAKAO_CHANNEL` 교체 (`docs/kakao-channel.md`)
- [ ] 제휴 금융사 수·누적 상담 건수를 실제 수치로 (근거 없는 숫자는 광고 규정 위반)
- [ ] 보조 전화번호 폼 접수처 연결 (`index.html`의 `form#consultForm action` — Google Apps Script → 시트, Formspree 등)
- [ ] 위탁 금융사 준법감시인 심의 (상품 광고는 금융사 확인 필요)
- [ ] 개인정보처리방침 전문, 제3자(위탁 금융사) 제공 동의가 필요한지 확인
- [ ] 자료의 "미확인" 항목(규제지역 최신 목록, 비규제 LTV 70% 등)은 사이트에 확정 문구로 쓰지 않았음. 확인되면 추가
- [ ] 사진 4장은 위키미디어·플리커 CC 라이선스 (푸터에 출처 표기). 자체 사진이 생기면 교체
- [ ] `og:image`는 절대 URL로 바꿀 것 (도메인 확정 후)
